Supernova Notch

A free notch for Android tablets. Music, lyrics, volume, calendar and a water reminder, all from the top edge of the screen.

Install

The app needs the accessibility permission, because that is how Android lets a view sit above other apps.

  1. Download the APK from the releases page and open it. Allow installs from this source if asked.
  2. Open the app, then turn on Supernova Notch in Settings, Accessibility.
  3. Grant notification access so covers and song titles can be read.

FAQ

Does it send my data anywhere?

No. The only network requests are the lyrics lookup to LRCLIB (song title and artist) and, for Spotify covers, the image from their image server.

Why the accessibility permission?

Android has no other permission for drawing above other apps this way. The code is open, so you can check it.

Why does it ask to see all installed apps?

Android 11 hides other apps. Without it, the cover from Spotify cannot be opened.

Does it drain the battery?

On my tablet, about 2% of total usage. See the numbers above for context.
